# Git Commit

A brief hands the commit to the kit-commit procedure.

**Related:** [RULES](../RULES.md) · [versioning](./versioning-and-git.md) · [contracts](./contracts.md) · [kit-commit](../skills/kit-commit/SKILL.md)

## Brief

Name the staged change, the order of its parts, and any specification the user gave.

## Commit Messages Instruct

Invoke a sub-agent with the brief. The sub-agent takes the [kit-commit](../skills/kit-commit/SKILL.md) persona and follows that procedure.
